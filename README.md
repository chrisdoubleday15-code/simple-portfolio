# chrisdoubleday.com

Portfolio site for Christopher Doubleday, Senior Motion Designer.

Built with Astro, Tailwind CSS and Bunny Stream video, deployed on Vercel. Started from the open-source Astro Simple Portfolio template (MIT, see `LICENSE`).

## Commands

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # type-check + build to dist/
npm run preview  # preview the production build
```

Project conventions, video IDs and component notes live in `CLAUDE.md`.
